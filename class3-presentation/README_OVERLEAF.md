# Class 3 presentation — Overleaf

## Upload
1. Go to [overleaf.com](https://www.overleaf.com) (AGH login works).
2. **New Project → Upload Project** and upload `class3-presentation.zip`.
3. Open `main.tex`.
4. Menu → **Compiler: pdfLaTeX**.
5. Click **Recompile**.

## Files
- `main.tex` — presentation
- `beamerthemeAGH.sty` + `beamercolorthemeAGH.sty` — AGH Beamer theme (Polak)
- Keep these `.sty` files in the **same folder** as `main.tex`

## Alternative
Open Overleaf template [Beamer theme AGH](https://www.overleaf.com/latex/templates/beamer-theme-agh/kdgyvspcfhhz), then replace the example content with our `main.tex` body (keep `\usetheme{AGH}`).
